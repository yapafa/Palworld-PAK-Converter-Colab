## English

A Colab notebook adaptation designed to run the **[Palworld PAK Converter](https://www.nexusmods.com/palworld/mods/4615)** directly in Google Colab, removing the need for a Windows `.exe` environment.

### 💡 Motivation
I wanted to run this tool without relying on any Windows environment. With the assistance of Gemini, I translated the original script into a Google Colab version.
